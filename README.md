# POLICASTROSTUDIO

Site do estúdio criativo de Isadora e Guilherme Policastro de Assis, em Gravataí, RS.

- React + TypeScript + Vite, animações com GSAP
- Rotas com HashRouter (compatível com hospedagem estática)
- Publicação automática no GitHub Pages a cada envio para `main`

## Rodar localmente

```bash
npm install
npm run dev
```

Endereço publicado: https://isadorapolicastro.github.io/policastro-studio/
